# Wood Gate Beyond

เกมแอ็กชันดันเจียนแนว pixel art เล่นบนเบราว์เซอร์ (มือถือและคอม) — ไฟล์เดียว `index.html` ไม่ต้อง build

## วิธีเล่น

- **จอยสติ๊ก** (ซ้ายล่าง) เดิน 8 ทิศ • คีย์บอร์ด: ลูกศร / WASD
- **โจมตี** ปุ่มแดง หรือ Space • **สกิล** ปุ่มม่วง หรือ E
- **เก็บของ / คุยกับพ่อค้า** ปุ่มเขียว หรือ F • **ยา** ปุ่มมุมซ้ายล่าง หรือ 1 / 2
- **หยุดเกม** ปุ่ม ⏸ หรือ Esc / P

เดินเข้าประตูหน้าดันเจียนเพื่อลงไปสู้ เคลียร์มอนสเตอร์ทั้งหมดแล้วเข้าพอร์ทัลเพื่อไปด่านถัดไป ทุก 10 ด่านมีบอส

## รันในเครื่อง

เปิดผ่านเว็บเซิร์ฟเวอร์ (เปิดไฟล์ตรงๆ รูปจะโหลดไม่ได้):

```bash
npx http-server -p 8080
```

แล้วเข้า http://localhost:8080

## โครงสร้าง

```
index.html     ตัวเกมทั้งหมด (HTML + CSS + JavaScript)
sprites/       รูป pixel art (ตัวละคร มอนสเตอร์ อาวุธ ฉาก ไอเทม)
```

## หมายเหตุ
